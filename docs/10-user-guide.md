# WorkEnglish Coach 用户指南

> 面向唯一使用者（你本人）的操作手册。所有数据都在本机，无云服务。

## 1. 安装说明

### 1.1 安装包（推荐）

1. 构建：`npm run package:win`
2. 产物：`release/WorkEnglish Coach Setup 0.1.0.exe`（NSIS 安装向导，约 86 MB）
3. 双击运行安装向导，默认安装到 `C:\Program Files\WorkEnglish Coach`。
4. 卸载：控制面板 → 程序和功能 → WorkEnglish Coach → 卸载。**卸载只删除程序文件，你的学习数据不受影响**（见第 4 节）。

### 1.2 开发模式

```bash
npm install        # 首次
npm run rebuild    # Electron 升级或 better-sqlite3 变化后
npm run dev
```

开发模式与安装包共用同一个数据目录（第 4 节），两边数据互通。

### 1.3 免安装目录版（调试用）

```bash
npm run package:win:dir
# 产物：release/win-unpacked/WorkEnglish Coach.exe，双击即用
```

## 2. API 配置说明

### 2.1 位置

主界面 → **设置** 页：

| 字段 | 说明 |
| --- | --- |
| Base URL | OpenAI 兼容端点的 `/v1`，例如 `http://127.0.0.1:12346/v1`、`https://api.openai.com/v1` |
| 模型 | 任意该端点支持的模型 id，例如 `qwen3.8-27b`、`gpt-4o-mini` |
| 超时（秒） | 单次 AI 请求超时。默认 30 秒；**本地小模型 / reasoning 模型建议 120 秒** |
| API Key | 可留空（本地模型不需要）；填写后存入**系统凭据管理器**（Windows Credential Manager），不写入数据库、不写入日志 |

点击 **保存设置** 后，设置写入本地 SQLite，Key 写入系统凭据存储，两者都会弹出确认提示。

**测试连接**：该页的「测试连接」按钮会发起一次真实的最小 AI 请求（要求模型只回复 “pong”），用表单**当前**的 Base URL / 模型 / 超时验证端点是否可用；成功时显示响应耗时（毫秒），失败时显示原因（超时 / 网络 / 认证 / 响应异常）。未保存的表单值也可以直接测试；API Key 不经界面传输，由主进程直接从系统凭据存储读取（未配置 Key 会提示先保存 Key）。

### 2.2 使用流程

1. 设置好 API 后，在**工作区**填写「中文原意」和「英文草稿」，点击 AI 纠错。
2. 结果卡片返回：最小修改版、自然表达版、问题分类列表。
3. 点击 **确认并保存**：样本、错误、知识点、表达全部落库，并生成错误档案与复习任务（详见 docs/01、04）。
4. 在**复习**页按间隔复习；答对/答错会驱动调度（答错当天再来，答对间隔拉长）。

### 2.3 修改 / 清除 Key

- 修改：Key 卡片填写新值并保存（会覆盖旧值）。
- 清除：Key 卡片上的 **清除 API Key** 按钮（有二次确认）。
- 手动清除：`cmdkey /list` 查看，`cmdkey "WorkEnglish Coach"` 删除（凭据名称 = 应用名）。

## 3. 隐私说明

| 项 | 行为 |
| --- | --- |
| 数据位置 | 全部在本机 `%APPDATA%\WorkEnglish Coach\`（见第 4 节），**无云端同步、无账号系统** |
| AI 请求 | 仅发往你在设置里填写的 Base URL。请求内容 = 中文原意 + 英文草稿 + 系统提示词；除此之外不上传任何数据 |
| API Key | 只存 Windows 凭据管理器（DPAPI 加密），不进 SQLite、不进日志、不进导出文件 |
| 其他应用 | **不读取**剪贴板、邮箱、聊天记录；**不自动发送**任何邮件/消息。所有输入都是你手动粘贴的 |
| 录音 | 仅在你点击录音按钮、系统授予麦克风权限后采集；文件只存在本机 `recordings/` 目录 |
| 日志 | 生产包不写应用日志文件；开发模式日志只到控制台 |
| 更新 | 不自动检查更新、不上传任何使用统计 |

隐私边界：AI 供应商（你配置的端点）会看到你发送给它的文本。如介意，使用本地模型端点（如本机部署的 OpenAI 兼容服务）即可做到数据完全不出本机。

## 4. 数据目录说明

**根目录**：`%APPDATA%\WorkEnglish Coach\work-english-coach\`（即 `C:\Users\<你>\AppData\Roaming\WorkEnglish Coach\work-english-coach\`）

| 文件/目录 | 内容 |
| --- | --- |
| `work-english-coach.db` | SQLite 主库：设置、错误档案、表达库、沟通样本、复习任务、复习记录（6+1 张表，结构见 docs/03） |
| `work-english-coach.db-wal` / `-shm` | SQLite WAL 模式文件，**备份时要一起复制** |
| `recordings/` | 录音文件（`.webm`，仅录音页手动点击产生） |

开发/测试覆盖（不需要一般不用）：环境变量 `WEC_DB_DIR` / `WEC_DB_FILE` / `WEC_REC_DIR`。

> 程序安装目录（`C:\Program Files\...`）内**没有任何**你的学习数据——升级、重装、卸载都不会动到这里。

## 5. 故障排查说明

| 症状 | 可能原因与处理 |
| --- | --- |
| AI 纠错报「请求超时」 | reasoning / 本地大模型推理慢。把设置里的**超时（秒）调大到 120**；仍超时则检查端点是否可达（浏览器里访问 `{Base URL}/models`） |
| AI 纠错报「返回结构无效」 | 模型没有按约定返回 JSON（小模型偶发）。直接重试即可；连续失败可换更强的模型 |
| AI 纠错报「认证失败」 | Key 错或端点要求认证。重新填写 Key；本地无认证服务留空 |
| 录音按钮点不动 / 无声音 | Windows 设置 → 隐私 → 麦克风，确认「允许桌面应用访问麦克风」；或换一个麦克风设备 |
| 复习页没有任务 | 正常现象：复习任务只在「确认并保存」/ 错误档案手动生成时产生，且按间隔调度（见 docs/04 第 6 节）。等间隔到期或换任务类型 |
| 界面卡死 / 窗口异常 | 完全退出后重开。数据都在 DB 里，重启不丢 |
| 怀疑数据库损坏 | 先按第 7 节备份现有文件，再重开应用观察；必要时删除 `work-english-coach.db*` 三个文件重建（**会清空全部学习数据，先备份！**） |
| 启动报 better-sqlite3 / keytar 错误 | 开发模式：`npm run rebuild`；安装包：重装最新版 |
| 端口被占（只影响开发） | `netstat -ano | findstr 5173`，`taskkill /PID <pid> /F` |

排查时如果需要看日志：开发模式的终端输出（`npm run dev` 的 console）是唯一的诊断来源，格式为 `[dev] [ipc:<频道>] ...`。

## 6. AI 服务兼容性说明

### 6.1 协议要求

应用只依赖 **OpenAI Chat Completions 兼容接口**：

- 端点：`POST {Base URL}/chat/completions`（Base URL 以 `/v1` 结尾，末尾斜杠可有无）
- 认证：`Authorization: Bearer <API Key>`（Key 为空则不带该头）
- 请求体：`{ model, messages: [{role, content}...], temperature, max_tokens, timeout(客户端侧) }`
- 期望响应：`choices[0].message.content` 为字符串，内容是 **JSON**（由提示词约束，不依赖 `response_format` 参数）

### 6.2 已知可用

| 服务 | Base URL 示例 | 备注 |
| --- | --- | --- |
| 本机 OpenAI 兼容测试服务 | `http://127.0.0.1:12346/v1` | `qwen3.8-27b`，reasoning 模型，超时建议 ≥120s |
| OpenAI 官方 | `https://api.openai.com/v1` | 标准兼容 |
| 任何 vLLM / llama.cpp server / Ollama（`/v1` 兼容模式） | `http://127.0.0.1:<port>/v1` | 留空 Key 即可 |

### 6.3 行为约束（docs/04 合同摘要）

- 应用要求 AI 返回严格 JSON（Zod 校验，非法即报错重试，不入库脏数据）。
- AI 返回的修改**不能**直接算作你「掌握」——掌握只由复习页的独立输出判定。
- 提示词禁止 AI 改动日期、数字、人物、责任人和承诺程度。
- 超时由客户端强制执行（`AbortController`），不会无限挂起。

### 6.4 换模型注意

- 模型越弱，「返回结构无效」概率越高；建议至少 7B 以上的指令遵循模型。
- reasoning 模型会把 token 花在思考上，`max_tokens` 需要足够（应用已按提示词需求设置），超时也要放宽。
- 应用对模型无任何微调/适配，纯 prompt 契约——新模型先在「工作区」跑一次纠错验证即可。

## 7. 如何备份数据

### 7.1 首选：应用内导出（结构化 JSON）

设置页 → **数据管理** → **导出数据** → 选择保存位置。
产物：一个 JSON 文件，格式 `wec-export/v1`，包含：设置、错误档案、表达库、沟通样本、复习任务、复习记录（含 JSON 字段解码）。**不含 API Key**。

> 说明：导出是只读快照，当前版本没有「从 JSON 导入恢复」功能。JSON 的用途是归档、迁移参考与长期保存；要真正恢复到另一个环境，用 7.2 的文件复制。

### 7.2 完整备份：复制数据目录（推荐定期做）

1. **完全退出应用**（托盘/任务栏确认无进程：`tasklist | findstr WorkEnglish`）
2. 复制整个目录到备份位置（U 盘 / 网盘 / 另一块盘）：
   ```
   %APPDATA%\WorkEnglish Coach\work-english-coach\
   ```
   （必须包含 `.db`、`.db-wal`、`.db-shm` 三个文件——应用退出后 WAL 会自动合并进 `.db`，所以正常退出后复制 `.db` 一个文件也足够）
3. 恢复：把目录复制回原位再启动应用即可。

### 7.3 备份什么、多久一次

| 数据 | 备份方式 | 频率 |
| --- | --- | --- |
| 学习数据（DB） | 7.2 复制目录 | 每周或每完成一个学习阶段 |
| 录音（如有） | 同目录的 `recordings/` 一起复制 | 同上 |
| API Key | **不需要备份**（在系统凭据里，新机器重新填写一次即可；如换机且同一 Windows 账号，可用系统「凭据管理器」迁移） | — |

### 7.4 清除数据

- 只清学习数据、保留设置：设置页 → **删除全部数据**（有二次确认；会清空 6 张学习表，录音文件保留在磁盘需手动删）。
- 彻底清除：删除整个数据目录（7.2 的路径）+ `cmdkey "WorkEnglish Coach"` 删凭据。
